# Generador-de-Hilos

## 📝 Descripción
Generador-de-Hilos es un proyecto personal desarrollado por **Diego Rueda** como parte de su portafolio de desarrollo de software. Este repositorio contiene el código fuente, la documentación y los recursos necesarios para comprender, ejecutar y extender el proyecto. El objetivo es demostrar buenas prácticas de ingeniería de software, integración continua y despliegue automatizado, manteniendo un código limpio, modular y mantenible.
