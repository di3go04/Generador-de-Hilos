🔍 Diagnóstico: por qué se cuelga y cómo se soluciona

1. stdin bloqueante — Sin -y ni -nostdin, ffmpeg espera input del usuario (overwrite prompt) → cuelga para siempre. Solución: -y -nostdin en los args.

2. Promesa no resuelta — ffmpeg.exec() devuelve una promesa que depende de postMessage del worker. Si el worker crashea o se cuelga, la promesa nunca se resuelve. Solución: Promise.race con timeout de 30s + .terminate().

3. Codec incompatible — MPEG‑4 Visual, MPEG‑2, etc. no son copiables a MKV sin recodificar. Solución: detectar con ffprobe + fallback a libx264/aac.

4. Worker mal inlinado — Si el import() dinámico dentro del worker falla, el worker nunca responde. Solución: self‑test que escribe un WAV y lo convierte con copy.

5. Archivo de salida no creado — El exec() reporta éxito pero no escribe nada. Solución: listDir('/') después del exec para verificar.
